# 2026-09-05 — SEO P0：canonical/hreflang/og/JSON-LD 指向 localhost

## 症状
线上首页 `<link rel=canonical>`、8 语言 + x-default hreflang、og:url/twitter、
Organization/Breadcrumb JSON-LD 全部输出 `http://localhost:3000`。

## 根因（已定位）
`.env.local` 里 `NEXT_PUBLIC_APP_URL = "http://localhost:3000"`（本地 dev 用于
auth 回调/支付回调）。`NEXT_PUBLIC_*` 在构建期被内联，`opennextjs-cloudflare build`
（内部跑 next build）会加载 `.env.local`（wrangler.toml 的 `[vars]` 是运行时变量、
不作用于构建期），于是 `envConfigs.app_url` 在**生产构建**里被解析成 localhost。

`envConfigs.app_url` 被广泛消费：seo.ts（canonical/hreflang/og）、首页 page.tsx 的
JSON-LD `baseUrl`、root layout 手注的 hreflang、sitemap/robots、auth canonical 等，
所以一处污染全站 SEO 输出全指向 localhost。

## 修复（本次，3 处代码改动）
1. `src/config/index.ts`：新增 `PRODUCTION_APP_URL = 'https://weddingcrestdesign.com'`
   与 `resolveAppUrl()`；生产环境(NODE_ENV=production)遇 localhost/127.0.0.1 一律
   回落到正式域名。`app_url` 与 `auth_url` 都走 `resolveAppUrl()`。
   —— 这是单点修复，所有走 `envConfigs.app_url` / `getAllConfigs().app_url` 的
   SEO 面自动修复；dev 环境仍保持 localhost（auth 回调不受影响）。
2. `src/app/layout.tsx`：新增 `export const metadata = { metadataBase: new URL(envConfigs.app_url) }`
   作兜底（相对 URL 的解析基准）。
3. `src/middleware.ts`：新增 www→apex 规范化 301（host 为 `www.weddingcrestdesign.com`
   时跳到 `https://weddingcrestdesign.com`，保留 path+query）。

校验：`pnpm exec eslint` 三个文件 + `pnpm exec tsc --noEmit` 均通过。

## 待办 / 后续（用户报告里的次一级问题）
- **http→https 301**：需在 Cloudflare 后台 SSL/TLS → Edge Certificates → 开启
  "Always Use HTTPS"（代码/Worker 层无法可靠拿到访问者协议；cf-visitor 头可读但
  建议直接边缘层做）。Google 目前索引的是 `http://weddingcrestdesign.com`，说明该开关未开。
- **www 归一化**：本次已加 middleware 301（兜底），更稳的是 Cloudflare Redirect Rule
  `www.weddingcrestdesign.com/*` → `https://weddingcrestdesign.com/$1`（覆盖所有请求含静态资源）。
- **JS 渲染骨架屏**：hero 画廊 + 6 个风格区块源码是 aria-busy 骨架屏，首轮抓取正文少；
  建议给每个工具页补 SSR 图文介绍段（本次未做，属内容优化建议）。
- **部署**：改完后需 `npm run cf:deploy`（cf 分支），重建后重新抓取验证。注意清 NODE_OPTIONS
  防 safe-delete shim 干扰（见 09-03 记录）。

  2. `src/app/[locale]/(landing)/page.tsx`：Organization JSON-LD 改为函数 `buildOrganizationJsonLd(logoUrl)`，
     在组件里 `getAllConfigs()` 取 `app_logo` 注入 `logo` 字段。
