## footer 联系表单「Send Message」返回 missing_parameter: sender name is missing（已定因修复）

- 根因：线上 `"wedding-crest".config` 里 `brevo_sender_name = ""`（空串），brevo.ts 把空串原样塞进
  `sender.name`，Brevo 以「present but empty」拒绝 → 400 `missing_parameter: sender name is missing`，
  经 brevo.ts 的 `` `${code}: ${message}` `` 拼装后正是前端 toast 内容。
  同时确认 `resend_api_key` 未配置，所以 Brevo 是唯一/默认出口；验证邮件、找回密码邮件同链路，同样受影响。
- 证据：直接连线上 Supabase（schema `"wedding-crest"`）读 config；成对探针
  「旧载荷(空 name) → 400 sender name is missing」vs「新载荷 → 400 仅报 to 非法」，两个探针都不发信，零成本复现。
- 修复：
  1. `src/extensions/email/brevo.ts` 新增 `parseEmailAddress()` / `resolveSenderName()`，sender 的 name/email 各自兜底，
     修掉 `email.from` 分支把 `Name <addr>` 整串当 email 的老 bug；缺 senderEmail 时返回可读错误。

  3. `src/shared/actions/contact.ts`：provider 原始报错只进 `console.error`，前端只看到通用文案。
